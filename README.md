## FitLog 

FitLog is a premium, modern web application designed for fitness enthusiasts to browse a comprehensive workout library, plan their daily routines, and organize their fitness journey with a sleek, dark-mode aesthetic. 

#  Technologies Used 

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Server Components)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management & Persistence**: React Context API & `localStorage`
- **Notifications**: [React Hot Toast](https://react-hot-toast.com/)
- **Deployment**: [Vercel](https://vercel.com/)

# 5 Key Features 

1. **Dynamic Workout Library**: Fetches and renders live API data to display comprehensive exercises, including images, targeted muscle groups, durations, equipment needed, and calories burned.
2. **Interactive Daily Planning**: Seamlessly add workouts to "Today's Plan" or "Save for Later" with a single click from the workout details page.
3. **Advanced Sorting Capabilities**: Optimize your routine by dynamically sorting your planned workouts by Duration, Calories Burned, or Rating.
4. **Persistent State Management**: Your customized daily plans and saved routines are automatically synchronized to `localStorage`, persisting seamlessly across browser refreshes or accidental tab closures.
5. **Modern, Responsive UI**: Features a highly polished, dark-mode-first design with striking neon green accents, complete with custom 404 error pages, global loading animations, and crisp toast notifications.
